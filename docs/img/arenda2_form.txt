Описание скриншота: Страница «Товар аренды»
============================================

Общее назначение:
Форма открывается в модальном окне и предназначена для добавления или редактирования отдельной товарной позиции в документе аренды. Заголовок окна — «Товар аренды #NNN» с иконкой с символом аренды. 

Поля формы (сверху вниз, слева направо):

Товар: Поле выбора (справочник) для указания арендуемого товара. Обязательное для заполнения. Справа от поля есть кнопки «X» (очистить), стрелка вниз (открыть список товаров) и «+» (создать новый товар).

Возвращён: Чекбокс (флажок). Если установлен, значит, конкретный товар по этой позиции возвращён. Может изменять дату и время возврата и, сдедовательно, пересчитывать стоимость аренды.

Количество: Числовое поле со стрелками вверх/вниз для изменения значения. Это поле отображается только если у товара не включен признак «Без количества». Приложение может ограничивать количество выдаваемого товара если на данном участке не хватает его остатка. На ограничение влияет параметр настройки "Запрет отрицательных остатков" а также флаг товара "Не вычислять остаток".

Начало: Дата и время начала аренды. Эти поля доступны только для чтения и предназначены для отображения времени начала аренды.

Возврат: Дата и время возврата конкретного товара. Может отличаться от времени возврата других товаров в документе. Влияет на количество "Часов", "Дней" и "Месяцев" а также на выбранные тарифы стоимость аренды.

Блок тарифов (три колонки):
Этот блок может изменяется в зависимости от параметров настройки приложения (Показывать поле Часов, Показывать поле Дней, Показывать поле Месяцев). В данном примере видны все три колонки.

"Часов": Поле для ввода количества часов аренды в формате чч:мм. Слева и справа от поля расположены кнопки «Минус 1» и «Плюс 1» (треугольники) для уменьшения/увеличения значения на 1 час. Влияет на стоимость аренды.

"За час": Поле, отображающее тариф за час. Автоматически выбирается из таблицы "Тарифы" данного товара. Это поле доступно только для чтения, если не включен параметр настройки «Тарифы вводятся вручную». 

"Дней": Поле для ввода количества дней аренды. Также имеет кнопки «Минус 1» и «Плюс 1». Влияет на стоимость аренды.

"За день": Поле, отображающее тариф за день. Автоматически выбирается из таблицы "Тарифы" данного товара. Доступно только для чтения (аналогично полю «За час»).

"Месяцев": Поле для ввода количества месяцев аренды. Влияет на стоимость аренды.

"За месяц": Числовое поле, отображающее тариф за месяц. Автоматически выбирается из таблицы "Тарифы" данного товара. Доступно только для чтения, если не включен параметр настройки «Тарифы вводятся вручную».

Блок выбора тарифа:

"Тарифный план": Поле выбора (справочник). В примере выбрано: "Обычный". Этот выбор определяет, какая группа тарифов будет использоваться для расчёта стоимости.

"Название тарифа": Поле выбора (справочник). Здесь можно выбрать конкретный «Фиксированный» тариф. При выборе фиксированного тарифа поля «Часов», «Дней», «Месяцев» и их тарифы скрываются. Фиксированный тариф не зависит от "Дней", "Часов" и "Месяцев". Например тариф "Неделя".

Финансовые поля:

"Скидка %": Числовое поле для указания процента скидки на данную позицию.

"Сумма скидки": Это поле только для чтения и рассчитывается автоматически.

"Сумма": Итоговая стоимость аренды данной позиции, рассчитывается автоматически.

"Залог": Сумма залога за данную позицию, рассчитывается автоматически.

Дополнительно:

"Примечание": Текстовое поле для произвольного комментария к данной позиции.

Нижняя панель:

Справа расположены две кнопки:

Сохранить (с иконкой дискеты) — сохраняет изменения и закрывает форму.
Отменить (с иконкой крестика в круге) — закрывает форму без сохранения.


Рекомендации для генерации документации:
При создании HTML-страницы для формы «Товар аренды» (по аналогии с sklad-prodazha.html или sklad.html) можно использовать следующий текст:

Форма «Товар аренды»

Форма предназначена для добавления и редактирования отдельной товарной позиции в документе аренды. Она открывается из вкладки «Товары» документа «Аренда».

Основные поля:

Товар — обязательное поле для выбора арендуемого товара из справочника.

Возвращён — флажок, отмечающий факт возврата данного товара.

Количество — количество единиц товара (отображается, если у товара не включен признак «Без количества»).

Начало — дата и время начала аренды (только для чтения, наследуется из документа).

Возврат — дата и время планируемого возврата (редактируется для каждой позиции).

Блок тарифов:

Поля «Часов», «Дней» и «Месяцев» отображаются в зависимости от параметров настройки приложения (Показывать поле Часов, Показывать поле Дней, Показывать поле Месяцев).

Поля «За час», «За день» и «За месяц» показывают соответствующие тарифы. Они доступны для редактирования только если включен параметр «Тарифы вводятся вручную».

Слева и справа от полей количества расположены кнопки «Минус 1» и «Плюс 1» для быстрого изменения значения.

Выбор тарифа:

Тарифный план — выбор группы тарифов (например, «Обычный», «Праздничный»).

Название тарифа — выбор конкретного тарифа, в том числе фиксированного (например, «Недельный»). При выборе фиксированного тарифа поля количества и тарифов скрываются.

Финансовые поля:

Скидка % — процент скидки на позицию.

Сумма скидки — рассчитывается автоматически (только для чтения).

Сумма — итоговая стоимость аренды позиции (только для чтения).

Залог — сумма залога за позицию (только для чтения).

Примечание — произвольный комментарий.

В нижней части формы расположены кнопки Сохранить и Отменить.

Это описание полностью соответствует как визуальным данным со скриншота, так и технической логике, изложенной в файле arenda.txt.
