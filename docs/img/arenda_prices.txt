Описание скриншота: Вкладка «Тарифы» страницы «Товар»

Общее назначение:
Вкладка «Тарифы» предназначена для настройки списка тарифов аренды для конкретного товара. Она отображается только в том случае, если включен хотя бы один из трёх параметров настройки приложения: «Показывать поле Часов», «Показывать поле Дней» или «Показывать поле Месяцев».

Верхняя панель:

Заголовок окна: «Товар: XXXXX» с иконкой символом товара.

Вкладки: Форма содержит несколько вкладок: «Параметры», «Прочее», «Остатки», «История» и активная вкладка «Тарифы» (выделена оранжевым цветом).

Поле «Тарифный план»: Расположено над таблицей. Поле выбора (выпадающий список) для указания тарифного плана {ссылка на страницу prplan.html}. По умолчанию выбран первый тарифный план. В примере — "Обычный". 
В таблице тарифов показываются записи только о тарифах выбранного тарифного плана.

Панель инструментов (над таблицей):
Слева расположены стандартные кнопки управления таблицей:

Добавить (зелёный крестик) — создание нового тарифа.
Изменить (карандаш) — редактирование выделенного тарифа.
Удалить (красный крестик) — удаление выделенного тарифа.
Копировать (два листа) — создание копии тарифа.
Обновить (две стрелки по кругу) — перезагрузка данных.
Экспорт (лист с стрелкой) — выгрузка списка.
Печать (принтер) — печать списка.

Справа расположено поле «Быстрый поиск» с кнопкой "Искать" (лупа) и кнопка "Условия поиска".

Таблица «Тарифы»:
Таблица содержит следующие колонки (слева направо):

Чекбокс: Для отметки строк.

"Дней от": Начало периода в днях (например, 1, 2, 4, 8, 31). Видно только если включен параметр настройки «Показывать поле Дней».

"Дней по": Конец периода в днях (например, 1, 3, 7, 30, 9999). Видно только если включен параметр «Показывать поле Дней».

"За день": Тариф за день (например, 200, 175, 150, 120, 100). Видно только если включен параметр «Показывать поле Дней».

"Время от": Начало периода в часах (например, 1:00). Видно только если включен параметр «Показывать поле Часов».

"Время по": Конец периода в часах (например, 13:00, 0:59). Видно только если включен параметр «Показывать поле Часов».

"За час": Тариф за час (например, 10, 15). Видно только если включен параметр «Показывать поле Часов».

"За месяц": Тариф за месяц (например, 800, 1000, 700). Видно только если включен параметр «Показывать поле Месяцев».

Фиксированный: Признак фиксированного тарифа. Отображается в  как иконка «галочка». Если тариф фиксированный, он не умножается на количество часов, дней или месяцев.

Название тарифа: Название тарифа (например, "Первый день", "Дни 2 и 3", "Сутки фиксированный", "От часа до 13:00"). 


Нижняя панель:

Справа расположены две кнопки:

Сохранить (с иконкой дискеты) — сохраняет изменения и закрывает форму.
Отменить (с иконкой крестика в круге) — закрывает форму без сохранения.


Рекомендации для генерации документации
При создании HTML-страницы для вкладки «Тарифы» (по аналогии с sklad.html или sklad-prodazha.html) можно использовать следующий текст, основанный на arenda.txt:

Вкладка «Тарифы» страницы «Товар»

На вкладке «Тарифы» страницы «Товар» расположена таблица со списком тарифов аренды товара. Эта вкладка выводится только если включен хотя бы один из трёх параметров настройки: «Показывать поле Часов», «Показывать поле Дней» или «Показывать поле Месяцев».

Над таблицей расположено поле выбора «Тарифный план». По умолчанию выбран первый тарифный план. В таблице «Тарифы» показываются записи только о тарифах выбранного тарифного плана и текущего товара.

Колонки таблицы «Тарифы»:

Дней от  — начало периода в днях.

Дней по  — конец периода в днях.

За день  — тариф за день.

Время от  — начало периода в часах.

Время по  — конец периода в часах.

За час — тариф за час.

За месяц  — тариф за месяц.

Фиксированный  — признак фиксированного тарифа (иконка «галочка»).

Название тарифа  — название тарифа.

Видимость колонок:

Колонки «Дней от», «Дней по», «За день» видны только если включен параметр настройки «Показывать поле Дней».

Колонки «Время от», «Время по», «За час» видны только если включен параметр настройки «Показывать поле Часов».

Колонка «За месяц» видна только если включен параметр настройки «Показывать поле Месяцев».

Форма «Тариф товара»:
При добавлении или редактировании тарифа открывается форма, содержащая следующие поля:

Товар — название товара (только для чтения).

Тарифный план — название тарифного плана (только для чтения).

Фиксированный тариф — чекбокс.

Дней от, по, За день, Выходной — поля для настройки дневных тарифов.

Время от, по, За час — поля для настройки часовых тарифов.

Месяцев от, по, За месяц — поля для настройки месячных тарифов.

Название — название тарифа. Поле обязательное для заполнения.

Видимость полей в форме зависит от параметров настройки («Показывать поле Часов», «Показывать поле Дней», «Показывать поле Месяцев»).
