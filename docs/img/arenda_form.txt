Описание скриншота: Форма документа «Аренда»
=============================================

Общий вид:
Форма открывается в модальном окне поверх основного интерфейса. Заголовок окна — «Аренда № NNN» с иконкой с символом аренды.

Вкладки:
Форма содержит три вкладки:

Параметры (по умолчанию активная, выделена оранжевым цветом).

Товары (похожа а аналогичную таблицу в документе «Продажа») содержит таблицу со списком арендуемых товаров документа.

Оплата (аналогична вкладке "Оплата" в документе «Продажа») содержит таблицу с операциями по оплате и возвратам денежных средств.

Содержимое вкладки «Параметры»
------------------------------
Вкладка состоит из нескольких логических блоков полей.

1. Основные реквизиты документа:

Номер: Текстовое поле, содержащее номер документа.

Фирма: Код фирмы. 

Создано: Два поля: дата и время создания документа. Эти поля доступны только для чтения.

2. Период аренды:

Начало: Поля для указания даты и времени начала аренды. Рядом с этими полями расположена кнопка с иконкой молнии для быстрой установки времени начала аренды у всех товаров данного документа.

Возврат: Поля для указания планируемой даты и времени возврата. У них также есть кнопка для быстрой установки времени возврата у всех товаров данного документа.  Может пересчитывать стоимость аренды (в зависимости от параметров настройки приложения "Не изменять «Дней» при досрочном возврате" и "Не возвращать деньги при досрочном возврате").

Возвращено: Чекбокс (флажок). Если он установлен, значит, все товары документа возвращены арендатором. Изменяет соответствующий флажок у всех товаров данного документа. Может изменять дату и время возврата и, следовательно, пересчитывать стоимость аренды.

Резервирование: Чекбокс. Если установлен, товар зарезервирован под эту аренду. Изменяет соответствующий флажок у всех товаров данного документа. Влияет на "занятость" товаров документа в указанный период времени.

3. Контрагент и финансовые условия:

Контрагент: Поле выбора (справочник) для выбора арендатора. Справа от поля есть кнопки: «X» (очистить), стрелка вниз (открыть список) и «+» (создать нового контрагента).

Скидка %: Числовое поле для указания процента скидки. Рядом — кнопка с иконкой молнии для установки скидки и автоматического перерасчёта у всех товаров документа.

Сумма скидки: Итоговая сумма скидки по документу.

Позиций: Числовое поле, показывающее количество товарных позиций в документе.

Итоговая сумма: Итоговая стоимость аренды документа.

Оплачено: Числовое поле, показывающее сумму внесённой оплаты.

Сумма залога: Числовое поле для указания общей суммы залога по всем товарам документа.

4. Дополнительная информация:

Сотрудник: Поле выбора (справочник) для указания ответственного сотрудника.

Участок: Поле выбора (справочник) для указания участка или склада, с которого выдаётся товар.

Вид платежа: Выпадающий список для выбора способа оплаты.

Примечание: Текстовое поле для произвольного комментария к документу.

5. Нижняя панель:

Справа: три кнопки управления:

Применить (с иконкой галочки в круге) — сохраняет документ, не закрывая форму.
Сохранить (с иконкой дискеты) — сохраняет документ и закрывает форму.
Отменить (с иконкой крестика в круге) — закрывает форму без сохранения.

Рекомендации для генерации документации

При создании HTML-страницы для раздела «Аренда» (по аналогии с sklad-prodazha.html) можно использовать следующий текст:

Форма документа «Аренда»

Форма предназначена для создания и редактирования документа аренды. Она состоит из трёх вкладок: Параметры, Товары и Оплата.

Вкладка «Параметры» содержит основные реквизиты документа:

Номер, фирма, дата и время создания.

Период аренды: дата и время начала, дата и время планируемого возврата. Предусмотрены флажки «Возвращено» и «Резервирование».

Контрагент (арендатор), скидка, итоговая сумма, оплачено, сумма залога.

Ответственный сотрудник, участок, вид платежа и примечание.

Вкладка «Товары» содержит таблицу со списком арендуемых товаров. Её структура и функционал аналогичны вкладке «Товары» в документе «Продажа».

Вкладка «Оплата» содержит таблицу с операциями по оплате и возвратам денежных средств. Её структура и функционал  полностью аналогичны вкладке «Оплата» в документе «Продажа».

В нижней части формы расположены кнопки Применить, Сохранить и Отменить.
