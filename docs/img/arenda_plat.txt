Описание скриншота: страница  «Операция с деньгами»
===================================================

Общее назначение:
Форма открывается в модальном окне поверх интерфейса и предназначена для создания или редактирования отдельной финансовой операции (платежа или возврата) по документу аренды. Заголовок окна — «Операция с деньгами: #NNN» с иконкой доллара.

Поля формы (сверху вниз, слева направо):

Контрагент: Поле выбора (справочник) для указания контрагента, по которому проводится операция. Обязательное для заполнения. Справа от поля есть кнопки «X» (очистить), стрелка вниз (открыть список контрагентов) и «+» (создать нового контрагента).

Дата: Поле для выбора даты операции с помощью встроенного календаря. Обязательное для заполнения.

Время: Поле для ввода или выбора времени операции. 

Вид операции: Поле выбора (справочник) для указания вида операции. Обязательное для заполнения. При создании новой записи об оплате по умолчанию присваивается значение «Оплата аренды». Справа от поля есть кнопки «X» (очистить), "стрелка вниз" (открыть список) и «+» для добавления нового вида операции.

Финансовые суммы (четыре поля в одной строке):

Сумма прихода: Сумма поступивших денег.

Сумма расхода: Сумма выбывших денег (например, возврат залога).

Сумма: Итоговая сумма операции, которая рассчитывается автоматически как разница между приходом и расходом.

Тип: Определяется автоматически в зависимости от выбранного Вида операции (только для чтения).

Вид платежа: Группа радиокнопок для выбора способа оплаты. Обязательное для заполнения. Варианты:
Наличные (выбран в примере)
Безнал.
Карта
Прочее

Документ №: Текстовое поле (только для чтения), отображающее номер документа аренды, к которому привязана операция.

Тип документа: Текстовое поле (только для чтения), отображающее тип документа. В примере — Аренда.

Сотрудник: Поле выбора (справочник) для указания ответственного сотрудника. Обязательное для заполнения. 

Примечание: Текстовое поле для произвольного комментария к операции.

Нижняя панель:

Две кнопки:
Сохранить (с иконкой дискеты) — сохраняет операцию и закрывает форму.
Отменить (с иконкой крестика в круге) — закрывает форму без сохранения.


Рекомендации для генерации документации
При создании HTML-страницы для вкладки «Оплата» документа «Аренда» (по аналогии с sklad-prodazha.html или sklad.html) можно использовать следующий текст:

Вкладка «Оплата» документа «Аренда»

На вкладке «Оплата» находится таблица со списком платежей и возвратов по данному договору аренды. Функционал таблицы аналогичен таблице оплат в документах типа «Продажа».

Особенности:

При создании новой записи об оплате по умолчанию присваивается «Вид операции» = «Оплата аренды».

В панели инструментов таблицы доступны специальные кнопки:

«Оплата» — создаёт запись об оплате аренды на сумму, равную разнице между итоговой суммой документа и уже оплаченной суммой.

«Залог» — создаёт запись об оплате залога на сумму залога по документу (если залог ещё не оплачен).

«Возврат» — создаёт запись о возврате залога (если залог ещё не возвращён).


Форма «Операция с деньгами»:
Форма предназначена для создания или редактирования отдельной финансовой операции. Она содержит следующие поля:

Контрагент (обязательное) — выбор контрагента из справочника.

Дата (обязательное) и Время — дата и время операции.

Вид операции (обязательное) — тип операции (например, «Оплата аренды», «Возврат залога»).

Сумма прихода, Сумма расхода и Сумма — финансовые параметры операции. Поле «Тип» (Приход/Расход) определяется автоматически.

Вид платежа (обязательное) — способ оплаты: Наличные, Безнал., Карта, Прочее.

Документ № и Тип документа — информационные поля (только для чтения), показывающие привязку операции к документу аренды.

Сотрудник (обязательное) — ответственный сотрудник.

Примечание — произвольный комментарий.

В нижней части формы расположены кнопки Сохранить и Отменить.
