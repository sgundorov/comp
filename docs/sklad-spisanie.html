Списание товаров

Документ «Списание товаров» оформляет выбытие товаров со склада без их реализации: порча, брак, истечение срока годности, утеря, использование для внутренних нужд предприятия. Контрагент не указывается.

При "утверждении" документа количество товара на складе уменьшается. Товар выбывает из учёта.

Колонки таблицы "Списание":

  • Док. № — номер документа
  • Дата — дата создания
  • Участок — склад, с которого списывается товар
  • Сумма — итоговая сумма документа
  • Позиций — количество товарных позиций
  • Примечание — примечание к документу

Документы можно сортировать и искать по любой колонке. Имеется "колоночный фильтр" по участку.

Кнопка "Утвердить". Включение признака "Утверждено" изменяет остатки товаров документа на участке (складе). При этом в документе запрещаются любые изменения кроме поля "Примечание".

Форма документа "Списание"

Поля формы "Списание"

Док. №Автоматически формируется системой. Можно изменить вручную.

Вкладка "Товары" формы списания

На вкладке Товары добавляются списываемые позиции. Для каждой указывается товар, количество, цена, сумма и примечание.

При помощи кнопки "Импорт" в документ можно вставить список товаров, предварительно отмеченных на странице "Товары".
