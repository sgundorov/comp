Продажа товаров

Продажа — отгрузка товаров покупателю. Товар списывается со склада. Документ фиксирует реализацию товаров и служит основанием для формирования счёта покупателю.

Таблица документов продажи

На этой странице находится таблица со списком всех документов продажи.

Таблица документов продажи.

Колонки таблицы "Продажа":

  • Утв. — признак (значок) "Утверждено".
  • Док. № — номер документа.
  • Дата — дата оформления продажи.
  • Контрагент — покупатель.
  • Участок — склад, с которого отгружается товар.
  • Скидка % — процент скидки на.
  • Сумма — общая сумма документа.
  • Оплачено — сумма, оплаченная покупателем.
  • Позиций — количество товарных позиций.
  • Примечание — комментарий к документу.

Документы можно сортировать и искать по любой колонке. Имеется "колоночный фильтр" по контрагенту и участку.

Кнопка "Утвердить". Включение признака "Утверждено" изменяет остатки товаров документа на участке (складе). При этом в документе запрещаются любые изменения кроме поля "Примечание" документа.

Вкладка "Товары"

На этой вкладке находится таблица со списком товаров документа.

Вкладка "Товары" с перечнем отгружаемых позиций.

Форма записи о товаре документа содержит:

  • Товар — поле выбора номенклатуры с поиском (фильтром) по наименованию.
  • Количество — количество единиц товара.
  • Цена — цена за единицу.
  • Скидка — процент скидки на данный товар.
  • Сумма — итоговая сумма по товару, рассчитывается автоматически.
  • Примечание — комментарий к товарной позиции.

Проверка остатков

При выборе товара и вводе количества система автоматически проверяет остаток на выбранном складе. Если остаток недостаточен, программа выдаёт предупреждение. Нельзя продать товара больше, чем есть в наличии.

Вкладка "Оплата" документа

На этой вкладке находится таблица со списком платежей по этому документу. Форма записи об оплате описана в разделе "Кассовая книга".

Печатные формы

Для документа "Продажа" доступны следующие печатные формы:

  • Расходная накладная — основной сопроводительный документ.
  • Товарный чек — для розничных продаж.
  • Счёт-фактура — для налогового учёта.
  • Акт выполненных работ — для услуг.
  • УПД — универсальный передаточный документ.

Выбор шаблона печати осуществляется через меню Печать в панели инструментов таблицы. Шаблоны настраиваются в разделе Администрирование → Настройка документов.
