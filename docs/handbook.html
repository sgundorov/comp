Справочники

Справочники — это простые таблицы, содержащие базовую информацию, которая используется в других разделах приложения. Доступ к ним осуществляется через Главное меню → Справочники. Все справочники имеют стандартную таблицу с панелью инструментов и форму редактирования в модальном окне.

Подменю раздела Справочники.

Фирмы

Страница содержит перечень юридических лиц (компаний-организаций), от имени которых ведётся деятельность. Каждая фирма хранит полные регистрационные реквизиты, используемые в печатных формах документов (счета, накладные, акты).

Таблица справочника «Фирмы».

Колонки таблицы

  • Наименование — краткое название организации.
  • Полное наименование — полное официальное название.
  • ИНН — идентификационный номер налогоплательщика.
  • Адрес — юридический адрес организации.
  • Телефон — контактный телефон.
  • Банковские реквизиты — расчётный счёт, БИК, корреспондентский счёт, наименование банка.

Поля формы

Форма редактирования содержит все реквизиты юридического лица: наименование (краткое и полное), ИНН, КПП, ОГРН, юридический адрес, фактический адрес, телефон, факс, e-mail, банковские реквизиты (расчётный счёт, БИК, корр. счёт, банк), а также отметку об активности организации.

Реквизиты фирмы автоматически подставляются в печатные формы документов. Если в системе зарегистрировано несколько фирм, перед печатью можно выбрать, от имени какой организации формировать документ.

Города

Страница содержит перечень городов и населённых пунктов. Используется в адресах контрагентов и других справочниках.

Таблица справочника «Города».

Колонки таблицы

  • Наименование — название города или населённого пункта.
  • Область / Регион — регион, к которому относится город.
  • Страна — страна (выбор из справочника стран).

Поля формы

Форма содержит поле наименования города, поле выбора региона и поле выбора страны. Страна выбирается из справочника «Страны».

Страны

Страница содержит перечень стран. Используется в справочнике городов и в адресах контрагентов.

Таблица справочника «Страны».

Колонки таблицы

  • Наименование (рус.) — название страны на русском языке.
  • Наименование (англ.) — название страны на английском языке (необязательное поле).
  • Код — двухбуквенный или трёхбуквенный код страны (например, RU, US, DE).

Поля формы

Форма содержит три поля: название на русском, название на английском и код страны.

Участки

Страница содержит перечень складов и мест хранения товаров. Используется во всех складских документах для указания места хранения.

Таблица справочника «Участки» (места хранения).

Колонки таблицы

  • Наименование — название склада или участка.
  • Адрес — фактический адрес расположения склада.
  • Ответственный — сотрудник, ответственный за данный участок (выбор из справочника сотрудников).

Поля формы

Форма содержит поле наименования, поле адреса и поле выбора ответственного сотрудника. Участки используются в шапке и табличной части складских документов при выборе склада отправителя и получателя.

Состояния заявок

Страница содержит перечень статусов (состояний) документов. Например: «Черновик», «Проведён», «Отменён».

Таблица справочника «Состояния заявок».

Колонки таблицы

  • Наименование — название статуса.
  • Цвет — цветовая индикация статуса (например, зелёный для проведённых документов, красный для отменённых). Цвет отображается в таблицах документов в виде цветной метки.

Поля формы

Форма содержит наименование статуса и выбор цвета из палитры. Цвет используется для визуального выделения строк в таблицах документов.

Типы контактов

Страница содержит перечень типов контактов, используемых в карточке контрагента. Например: «Должность», «Телефон», «Email», «Сайт», «Факс», «Мессенджер».

Таблица справочника «Типы контактов».

Колонки таблицы

  • Наименование — название типа контакта.

Поля формы

Форма содержит только наименование типа. Справочник используется в блоке контактов на странице редактирования контрагента.

Виды рекламы

Страница содержит перечень рекламных каналов, по которым пришёл контрагент. Например: «Из поисковика», «По рекомендации», «Социальные сети», «Баннер».

Таблица справочника «Виды рекламы».

Колонки таблицы

  • Наименование — название рекламного канала.

Поля формы

Форма содержит только наименование. Значение выбирается в карточке контрагента для указания источника, откуда клиент узнал о компании. Позволяет оценивать эффективность рекламных каналов.
