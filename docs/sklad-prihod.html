Приход товаров

Документ Приход предназначен для оприходования товаров на склад — поступления товаров от поставщиков. После создания и сохранения документа «Приход» количество товаров на складе увеличивается.

Таблица документов «Приход».

Таблица приходов

При входе в раздел отображается список приходных документов. Каждая строка — отдельный приходный документ.

Колонки таблицы «Приход»:

  • Утв. — признак (значок) "Утверждено".
  • Док. № — номер документа.
  • Дата — дата поступления.
  • Контрагент — поставщик, от которого поступил товар.
  • Участок — склад, на который поступил товар.
  • Скидка % — скидка по документу (если применимо).
  • Сумма — общая сумма прихода.
  • Оплачено — сумма, оплаченная поставщику.
  • Позиций — количество товарных позиций в документе.
  • Примечание — комментарий к документу.

Документы можно сортировать и искать по любой колонке. Имеется "колоночный фильтр" по контрагенту и участку.

Кнопка "Утвердить". Включение признака "Утверждено" изменяет остатки товаров документа на участке (складе). При этом в документе запрещаются любые изменения кроме поля "Примечание" документа.

Форма документа «Приход»

Форма приходного документа.

Форма "Приход" состоит из трех вкладок. Основные поля ввода расположены на вкладке «Параметры»:

ПолеОписание поля
НомерНомер документа. Обычно заполняется автоматически, но может быть изменён вручную.
ДатаДата поступления товара. По умолчанию — текущая дата.
ВремяВремя создания документа.
КонтрагентПоставщик, от которого поступает товар. Выбирается из справочника контрагентов. Поле обязательное.
УчастокСклад, на который оприходуется товар. Выбирается из справочника участков.
СкидкаПроцент скидки на документ в целом. Кнопка "Установить скидку" устанавливает скидку у всех товаров этого документа. При этом пересчитывается сумма скидки.
Сумма скидкиСумма скидки документа. Рассчитывается автоматически на основе товарных позиций.
Итоговая суммаОбщая сумма документа. Рассчитывается автоматически на основе товарных позиций.
ПозицийКоличество строк товаров в документе. Рассчитывается автоматически.
ОплаченоСумма, которая оплачена поставщику. Рассчитывается на основе запией о платежах по данному документу.
Дата оплатыДата оплаты поставщику.
По документу №Номер документа поставщика (счёт, накладная), если требуется.
СотрудникСотрудник, создавший документ. Выбор из справочника.
ПринялСотрудник, принявший товар на склад. Выбор из справочника.
ПримечаниеПроизвольный комментарий к документу.

Поля, помеченные звёздочкой (*), являются обязательными для заполнения.

Вкладка «Товары» документа

Таблица товарных позиций документа «Приход».

На этой вкладке находится таблица списка товарных позиции документа. Для добавления записи о товаре нажмите кнопку «Добавить». В форме "Товар документа" указываются:

ТоварВыбор товара/услуги из справочника номенклатуры. При поиске товара используется фильтр по наименованию.
Кол-воКоличество поступившего товара.
ЦенаЦена за единицу товара.
СкидкаСкидка на данную товарную позицию в процентах.
СуммаСтоимость позиции (количество x цена - скидка). Рассчитывается автоматически.
Сумма скидкиСумма скидки. Рассчитывается автоматически.
ПримечаниеКомментарий к товарной позиции.

При помощи кнопки "Импорт" в документ можно вставить список товаров, предварительно отмеченных на странице "Товары".

После добавления всех позиций сохраните документ нажатием кнопки «Применить» или «Сохранить». Они отличаются только тем что кнопка "Применить" не закрывает форму.

Вкладка «Оплата» документа

На этой вкладке находится таблица со списком платежей по этому документу. Запись об оплате имеет Вид операции расходного типа, поэтому сумма операции получается отрицательная.

Печать документа

Для документа «Приход» доступны следующие варианты печати:

  • Приходный ордер — типовая форма приходного складского ордера.
  • Накладная — печать накладной на поступление товаров.
  • Список приходов — печать списка приходных документов (все записи, выбранные или текущая страница).

Состав печатных форм настраивается в разделе «Администрирование → Настройка документов».

Экспорт

Таблицу приходов можно экспортировать в форматы CSV, Excel или HTML для дальнейшей обработки.
