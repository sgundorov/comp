Возврат поставщику

Документ «Возврат поставщику» (тип операции 110) оформляет возврат товаров обратно поставщику. Товары списываются со склада и выбывают из учёта.

Список документов

Основная страница показывает все документы возврата поставщику. В таблице отображаются колонки:

  • Номер — номер документа
  • Дата — дата создания
  • Контрагент — поставщик, которому возвращается товар
  • Участок — склад, с которого производится возврат
  • Скидка — сумма скидки
  • Сумма — итоговая сумма документа
  • Оплачено — сумма оплаты
  • Позиций — количество товарных позиций
  • Примечание — текстовое примечание

Товарная вкладка

На вкладке Товары добавляются позиции, подлежащие возврату. Для каждой позиции указывается товар, количество (отрицательное — уменьшает остаток на складе), цена, сумма и примечание.

Печать

Доступна печать возвратной накладной — стандартный печатный формуляр для передачи поставщику.
