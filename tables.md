country\_id - Страна (выбор из country) - В таблице "колоночный фильтр"

postindex - Почтовый индекс

address\_jur - Юридический адрес

address - Адрес

pasport - Паспорт

note - Примечание



Порядок вывода полей в таблице client.php:

ID, name, last\_name, first\_name, Категория, телефон, Email, сайт, город, страна, адрес, Виды деятельности, Прочее, Примечание



Порядок вывода и группировки полей в форме:



Вкладка "Общие":

Название (jur\_name) - 1я строка

Обозначение (name) - 2я строка

Фамилия + Имя, отчество - 3я строка

Телефон + Сотовый  - 4я

Email + Сайт - 5я

Категория + Скидка + Должность  - 6я

Виды деятельности - 7я. Справа кнопка для выбора Вида деятельности из выпадающего списка видов деятельности. Можно выбрать несколько вилов деятельности и они отобразятся в "прямоугольниках" в поле "Виды деятельности"

Поставщик + Проблемный + Организация + Не показывать  - 8я строка

juridical\_flag - Организация

Примечание - textarea в несколько строк высотой



Вкладка "Адрес":

Группа полей "Паспорт"

Серия, № (pasport) + Дата паспорта + Родился  - 1я строка

Выдан (pasp\_vydan) - 2я



Город + Страна + Индекс - 3я -  Поле "Страна" readonly - заполняется автоматически при выборе города

Адрес - 4я

Юрид. адрес - 5я

Дата создания - 6я



Вкладка "Реквизиты":

ИНН + КПП + ОГРН

ОКОНХ + ОКПО

Директор + Главбух

Банк (75%) + БИК (25% ширины)

Счет + Корсчет

Дополнительно - textarea
