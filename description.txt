Нужно разработать web-приложение на php и js.
Приложение предназначено для удобной работы с базой данных MySQL.
Приложение (специализированная СРM) реализует работу с таблицами базы данных: их просмотр, поиск в них данных и редактирование записей таблиц. А также формирование документов и отчетов.

Параметры подключения к базе данных (как и другие параметры настройки) должны находиться в отдельном конфигурационном файле config.php:

define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '1439');
define('DB_NAME', 'compan'); 

Работа с базой данных должна вестись через mysqli.

Приложение состоит в основном из двух видов страниц:

1) страниц таблиц данных, которые открываются через пункты и подпункты главного меню. Эти страницы предназначены для просмотра и поиска данных в соответствующей таблице базы данных.
В верхней части этих страниц находится строка горизонтального меню с выпадающими вертикальными подменю.

2) страниц форм редактирования записей. При помощи страницы-формы производится просмотр и редактирование выбранной в таблице записи. Страница-форма может быть модальной и тогда у нее не должно быть строки меню.

По умолчанию при запуске приложения открывается страница с таблицей, указанной в параметрах настройки программы. Например страница "Контрагенты". 

Страница с таблицей данных отображает одну из таблиц базы данных с органами управления отображения таблицы, поиска в ней и редактирования записи таблицы. В каждом окне таблицы есть кнопка "Добавить" (добавить новую запись) а также в каждой строке таблицы есть кнопки (иконки) "Открыть" (открыть запись), "Удалить" (удалить запись) и "Копировать" (создать новую запись на основе данной записи).

Каждая из этих кнопок открывает СТРАНИЦУ ФОРМЫ ЗАПИСИ таблицы в режиме создания, изменения или удаления записи.
На странице формы записи выводятся поля записи таблицы а также кнопки "Сохранить" и "Отменить", нажатие на которые закрывает окно формы записи и при этом производится возврат на страницу таблицы.
В режиме удаления записи кнопка "Сохранить" переименовывается в "Удалить".

Все элементы страниц приложения занимают на экране область шириной не более 1100 px. Если экран имеет большую ширину, то страницы центрируются по экрану.
Дизайн должен быть адаптивным и нормально отображаться на смартфоне. 
Таблицы с большим количеством колонок могут иметь фиксированную ширину большую чем ширина экрана смартфона. Тогда на смартфоне появляется ползунок для скроллинга по горизонтали.

#Общее описание страницы таблицы:#

В верхней части этого окна выводится заголовок страницы обычно в виде названия таблицы. Например "Клиенты", "Счета", "Сотрудники"...

В центре страницы выводится таблица с записями соответствующей таблицы базы данных.
В над каждой из колонок таблицы выводится название поля записи.
В самой левой колонке таблицы расположены "чекбоксы" для отметки записей. Чекбокс в заголовке этой колонки отмечает или снимает отметки у всех записей таблицы.
Во второй колонке таблицы находится кнопка (иконка) "Открыть".
В третьей колонке - кнопка "Удалить" 
В четвертой колонке - кнопка "Копировать" (создать новую запись на основе данной выделенной записи).
В следующих колонках таблицы отображаются поля записи в порядке указанном при описании данного окна.

Названия заголовков колонок (полей записи) из минимальная ширина и формат вывода описываются в описании конкретной таблицы.

Таблица выводит заданное в настройках число записей (например 20). Если всего записей в таблице базы данных больше, то под таблицей выводятся кнопки пагинации (для листания страниц) и отображается номер текущей страницы (например "2 из 55").

##Над таблицей расположены кнопки (иконки) - слева направо:##

- "Добавить" (иконка "+") - добавить новую запись
- "Обновить" - Перевывести данные таблицы
- "Экспорт" - Открывает меню вида экспорта таблицы в файл
- "Печатать" - Открывает меню выбора вида печатного документа
- Если в таблице есть хотя бы одна отмеченная запись, то появляется еще кнопка выбора действия с отмеченными записями. Ее название типа "Выбрано 3". При ее нажатии выпадает меню из пунктов: "Очистить выбор", "Инвертировать выбор", "Экспорт" и "Печатать". 

- Над таблицей также находится поле ввода для "Быстрого поиска" и слева от него кнопка "Искать".

- Кнопка "Фильтр" открывающее панель настройки фильтра.
- Кнопка "Сортировать" открывающая панель настройки способа сортировки записей.


#Общее описание страницы формы записи:#

В верхней части этого окна выводится заголовок страницы состоящий из названия таблицы и дополнительного поля из записи. Например "Клиент: Иванов Иван Петрович", "Счет № 12345"...

Пример заголовка страницы формы "Город": "Город: Москва".
Для новой страницы: "Город (новый)".
Для удаления "Город: Москва (удаление)".

В центре страницы формы расположены поля ввода для отображения или редактирования полей записи (в зависимости от режима формы).

Поля могут быть объединены в группы, которые могут иметь свои названия. 
Поля могут располагаться как друг под другом так и несколько полей в один ряд по горизонтали (только для экранов desktop и tablet). Порядок расположения полей задается при описании конкретной страницы.

Название (label) у поля ввода располагается над полем и выровнено по левой границе поля ввода.

##Возможные виды полей ввода:##

- Обычное поле для ввода с клавиатуры
- Поле выбора из справочника. В правой части этого поля имеется кнопка, нажатие на которую открывает "выпадающий список" для выбора из связанной таблицы-родителя. В верхней части выпадающего списка имеется поле ввода, предназначенное для поиска (фильтрации) данных списка по введенной подстроке.
- Поле типа "чекбокс".
- Поле переключатель типа "радио кнопки".
- Поля ввода даты с кнопкой, вызывающей "календарь" выбора даты.

В нижней части окна формы находятся кнопки "Сохранить" и "Отменить".
В режиме удаления записи кнопка "Сохранить" переименовывается в "Удалить".
При нажатии на кнопку "Сохранить" запись записывается в базу данных и делается возврат на страницу таблицы, из которой была открыта страница формы.
При нажатии на кнопку "Удалить" запись удаляется из базы данных и делается возврат на страницу таблицы, из которой была открыта страница формы. 
При нажатии на кнопку "Отменить" ничего не делается а производится только возврат на страницу таблицы, из которой была открыта страница формы.

#Пример страницы формы "Город":#

Поля формы записи о городе (сверху вниз):

- Город - поле ввода
- Страна - поле строка с выбором из таблицы country.nacountryme. Записывает выбор в поле city.country_id
- Примечание - поле ввода

Поля расположены друг под другом по вертикали.

Длина поля "Примечание" максимальная.
