Нужно разработать web-приложение на php и js.

Приложение предназначено для удобной работы с базой данных MySQL.

Приложение (специализированная СРM) реализует работу с таблицами базы данных: их просмотр, поиск в них данных и редактирование записей таблиц. А также формирование документов и отчетов.



Параметры подключения к базе данных (как и другие параметры настройки) должны находиться в отдельном конфигурационном файле config.php:



define('DB\_HOST', 'localhost');

define('DB\_USER', 'root');

define('DB\_PASS', '1439');

define('DB\_NAME', 'compan');



Работа с базой данных должна вестись через mysqli.

Приложение состоит в основном из двух видов страниц:



1\) страниц таблиц данных, которые открываются через пункты и подпункты главного меню. Эти страницы предназначены для просмотра и поиска данных в соответствующей таблице базы данных.

В верхней части этих страниц находится строка горизонтального меню с выпадающими вертикальными подменю.



2\) страниц форм редактирования записей. При помощи страницы-формы производится просмотр и редактирование выбранной в таблице записи. Страница-форма может быть модальной и тогда у нее не должно быть строки меню.

По умолчанию при запуске приложения открывается страница с таблицей, указанной в параметрах настройки программы. Например страница "Контрагенты".



Страница с таблицей данных отображает одну из таблиц базы данных с органами управления отображения таблицы, поиска в ней и редактирования записи таблицы. В каждом окне таблицы есть кнопка "Добавить" (добавить новую запись), "Изменить" (открыть запись), "Удалить" (удалить запись) и "Копировать" (создать новую запись на основе выделенной записи).



Каждая из этих кнопок открывает СТРАНИЦУ ФОРМЫ ЗАПИСИ таблицы в режиме создания, изменения, копирования или удаления записи.



На странице формы записи выводятся поля записи таблицы а также кнопки "Сохранить" и "Отменить", нажатие на которые закрывает окно формы записи и при этом производится возврат на страницу таблицы.

В режиме удаления записи кнопка "Сохранить" переименовывается в "Удалить".



Все элементы страниц приложения занимают на экране область шириной, заданной параметром настройки программы (по умолчанию не более 1100 px). Если экран имеет большую ширину, то страницы центрируются по экрану.



Дизайн всех страниц должен быть адаптивным и нормально отображаться на смартфоне.

Таблицы с большим количеством колонок могут иметь фиксированную ширину большую чем ширина экрана смартфона. Тогда на смартфоне появляется ползунок для скроллинга по горизонтали.

Формы редактирования записей тоже должны быть адаптивными и их ширина не должна быть больше ширины экрана устройства.

\##Таблица##



Под "тулбаром" находится таблица со списком записей указанной таблицы базы данных.



В колонках таблицы отображаются поля записи в порядке указанном при описании таблицы.

Названия заголовков колонок (полей записи) из минимальная ширина и формат вывода описываются в описании конкретной таблицы.



Таблица имеет постраничную пагинацию. Кнопки управления пагинацией находятся под таблицей.



Таблица выводит заданное в параметрах настройки приложения число записей (по умолчанию 20). Если всего записей в таблице базы данных больше, то под таблицей выводятся кнопки пагинации (для листания страниц) и отображается номер текущей страницы (например "2 из 55").



В таблице всегда есть одна выделенная цветом (текущая) строка (по умолчанию первая). С этой строкой работают кнопки тулбара. После операции с выделенной строкой (например изменения или добавления) выделение должно оставаться на этой строке. После удаления строки выделение переходит на следующую строку (если она есть) или на предыдущую строку если удаленная строка была последней. Переход выделения делается с учетом страницы таблицы и направления сортировки таблицы.



В таблице можно изменять ширину колонок путем "перетаскивания" правой границы колонки. Текущая ширина колонки запоминается.



В таблице можно изменять порядок следования колонок и отключать некоторые колонки. Это делается при помощи панели "Настройка столбцов таблицы".



Можно сортировать записи в таблице по значению любой колонки путем щелчка по заголовку колонки. Повторный щелч0к по заголовку колонки изменяет порядок сортировки на противоположный. Порядок сортировки показывается иконкой в правой стороне заголовка колонки.

При помощи панели "Сортировка" можно настроить более сложную сортировку по нескольким полям таблицы.



В таблице имеется "Быстрый поиск" (фильтрация записей) по заданной подстроке. При включении любого фильтра это фильтр отображается в информационной строке, которая появляется над таблицей. Например: "(Контрагент, Примечание Содержит "Арен")". В левой части информационной строки выводится иконка filter.png, а в правой иконка "X", нажатие на которую выключает фильтр). В информационной строке может показываться несколько включенных фильтров, каждый из которых можно отключить при помощи "X".

Найденные в полях таблицы подстроки выделяются цветом фона (с учетом заданных "Условий поиска").



У колонок, поля которых заполняются путем выбора из фиксированного списка или из связанной таблицы базы данных, имеется "колоночный фильтр". Он открывается кнопкой "Стрелка вниз" в правой части заголовка колонки. Нажатие на эту кнопку открывает панель выбора одного или нескольких возможных значений поля. Список значений по умолчанию состоит из первых 8-и записей. Слева от каждого значения списка имеется "чекбокс" для выбора этой записи. В верхней части этой панели есть поле для поиска записи (путем фильтрации записей в списке возможных значений).

В нижней части панели "колоночного фильтра" находятся кнопки "Применить" и "Сброс" для включения и сброса колоночного фильтра.

Включенный колоночный фильтр показывается в информационной строке над таблицей. Например "(Контрагент = Иванов)".



В таблице имеется возможность редактирования отдельного поля строки без открывания окна формы редактирования записи - "инлайн редактор". При наведении курсора мышки на любую ячейку таблицы (кроме полей "только для чтения") в правой части ячейки появляется кнопка (иконка "карандаш") нажатие на которую открывает панель редактирования поля. В этой панели находится поле для редактирования и кнопки "Сохранить" и "Отменить". Поле редактирования может быть любого допустимого типа: простое поле ввода, textarea, поле выбора (lookup), checkbox, выбор из заданного списка значений и т.п.



В таблице есть возможность "горизонтального скроллинга" ее колонок путем нажатия на клавиши Left и Right. При этом первые 3 колонки таблицы (по умолчанию) не скроллируются - остаются на месте. Остальные колонки при нажатии Left сдвигаются влево на одну колонку, а при нажатии Right - сдвигаются вправо.



Таблица поддерживает следующие "горячие клавиши":

\- Up - перемещение выделения строки вверх на одну строку. С учетом переключения страниц.

\- Down - перемещение выделения строки вниз на одну строку. С учетом переключения страниц.

\- PgUp - перейти на следующую страницу. Выделение на первой строке новой страницы.

\- PgDown - перейти на предыдущую страницу. Выделение на последней строке новой страницы.

\- Hоме - перейти к первой строке первой страницы.

\- End - перейти к последней строке последней страницы.

\- Click - выделить строку

\- Double Click - открыть форму редактирования записи

\- Enter - открыть форму редактирования записи

\-Insert - открыть форму создания новой записи
-Delete - открыть форму удаления записи

\##Панель Сортировка##

В этой панели можно настроить условия сортировки записей в таблице: по каким колонкам сортировать и в каком порядке: по убыванию или по возрастанию.

Заголовок панели: Сортировка

Под заголовком в одной строке расположены два поля выбора "Столбец" и "Направление" с общей меткой "Сначала по". В поле "Столбец" можно выбрать один из заголовков столбцов таблицы в выпадающем списке. В поле "Направление" выбирается направление сортировки для данного поля "По убыванию" или "По возрастанию".
Справа от поля "Направление" есть кнопка "x" для удаления этого уровня сортировки.
Ниже находится кнопка "+ Добавить уровень". При ее нажатии под строкой с полями первого уровня сортировки появляется еще одна строка с полями второго уровня сортировки и общей для них меткой "Затем по".
Ниже кнопки "+ Добавить уровень" имеются кнопки "Сортировать" и "Отменить".

При включении такой сортировки в заголовках колонок таблицы, которые участвуют с сортировке, добавляется цифра с номером уровня сортировки и иконка "Вверх" или "Вниз" в зависимости от установленного направления сортировки.

Если в таблице щелкнуть мышкой по заголовку колонки, то способ сортировки изменяется на "одноуровневый" по той колонке, в которой сделан щелчок.

Ниже находится список названий колонок с чекбоксами слева. По умолчанию все чекбоксы включены. Выключение чекбокса отключает видимость данной колонки в таблице.
Кнопками "Поднять" и "Опустить" можно изменять порядок колонок в таблице. Видимость и порядок колонок (а также их ширина) запоминаются для каждой таблицы в базе данных приложения.









\#Общее описание страницы формы записи:#



Страница форма обычно сделана на базе модального окна.



В верхней части окна формы выводится заголовок состоящий из названия таблицы и дополнительного поля из записи. Например "Клиент: Иванов Иван Петрович", "Счет № 12345"...



Пример заголовка страницы формы "Город": "Город: Москва".

Для новой страницы: "Город (новый)".

Для удаления "Город: Москва (удаление)".

Для копирования "Город: Москва (копия)".



В центре страницы формы расположены поля в для отображения или редактирования (в зависимости от режима формы) полей записи.



Поля могут быть объединены в группы, которые могут иметь свои названия.

Поля могут располагаться как друг под другом так и несколько полей в один ряд по горизонтали (только для экранов desktop и tablet). Порядок расположения полей задается при описании конкретной страницы.



Название (label) у поля располагается над полем и выровнено по левой границе поля ввода.
Исключение поле типа checkbox, у которого иконка и label выводятся в одну строку (иконка слева).





\##Возможные виды полей ввода:##



* Обычное поле для ввода с клавиатуры
* Поле выбора из справочника. В правой части этого поля имеется кнопка, нажатие на которую открывает "выпадающий список" для выбора из связанной таблицы-родителя. В верхней части выпадающего списка имеется поле ввода, предназначенное для поиска (фильтрации) данных списка по введенной подстроке.
* Поле выбора из заданного списка вариантов.
* Поле типа "чекбокс".
* Поле переключатель типа "радио кнопки".
* Поле ввода даты с кнопкой, вызывающей "календарь" выбора даты.



В нижней части окна формы находятся кнопки "Применить" (c иконкой accept.png), "Сохранить"  (save.png) и "Отменить" (cancel.png).

В режиме удаления записи кнопка "Сохранить" переименовывается в "Удалить" с иконкой delete.png.

При нажатии на кнопку "Сохранить" запись записывается в базу данных и делается возврат на страницу таблицы, из которой была открыта форма.

При нажатии на кнопку "Удалить" запись удаляется из базы данных и делается возврат на страницу таблицы, из которой была открыта страница формы.

При нажатии на кнопку "Отменить" ничего не делается а производится только возврат на страницу таблицы, из которой была открыта страница формы.

При нажатии на кнопку "Применить" запись записывается в базу данных но окно формы не закрывается.



При открытии формы курсор (фокус ввода) устанавливается на первое сверху поле (если оно не read only). При нажатии на клавишу Tab курсор последовательно обходит все поля и кнопки в направлении справа налево сверху вниз. С последней кнопки курсор переходит на первое поле.



Контрол, на котором находится фокус ввода выделяется цветной рамкой шириной в 2 px.





В левой части заголовка страниц таблицы и формы находится иконка, которая зависит от редактируемой таблицы базы данных. Название этой иконки состоит из названия таблицы базы данных (например city) и расширения "png".





\#Пример описания страницы таблицы "Города":#



Минимальная ширина этой таблицы 700 px.



Колонки таблицы "Города":

\- ID - целое число - поле id

\- Город - строка, выравнивание влево - поле city

\- Страна - поле выбора (лукап), выравнивание влево - поле country.country из связанной таблицы country

\- Примечание - строка, выравнивание влево - поле note



\#Пример страницы формы "Город":#



Поля формы записи о городе (сверху вниз):



\- Город - поле ввода

\- Страна - поле строка с выбором из таблицы country.country. Записывает выбор в поле city.country\_id

\- Примечание - поле ввода



Поля расположены друг под другом по вертикали.

Длина полей "Город" и "Страна" не во всю ширину экрана, а примерно в половину ширины (для desktop и tablet).

Длина поля "Примечание" максимальная.



\#Требования к цельности приложения#



Все требования к страницам таблиц и форм должны применяться ко всем вновь создаваемым страницам. Если на странице есть какие-либо отступления от описанного выше "стандарта", то они оговариваются особо при описании страницы.



Дизайн (стили) всех элементов страниц и контролов должен быть одинаковым на всех страницах приложения.

Функциональность всех таблиц и форм должна быть одинакова по всему приложению.

Внешний вид и функционал всех "стандартных" панелей должны быть одинаковы на всех страницах.
