1. **КРИТИЧНО: нет серверной аутентификации.** `GET /city.php` без сессии отдаёт HTTP 200 + 20 строк данных (`data-row-id` в HTML). Вход — только клиентский overlay в `lib/table-template.php:28-58`. AJAX-endpoint'ы тоже без guard'а.
2. **КРИТИЧНО: пароли в открытом виде.** `login_handler.php:28` — `$r['passw'] !== $password` (прямое сравнение строк, без `password_hash`).
3. **Нет CSRF-защиты** во всех POST-endpoint'ах.
4. **Дублирование:** 9 файлов на сущность × 32 сущности. В `111.txt` зафиксировано, что копипаста даёт «десятки ошибок» при создании новой таблицы; скилл-шаблон не помог.

6. **Нет миграций БД:** схема меняется ad-hoc в `config.php` (`ensure_*_table()`, `ALTER TABLE` на каждый запрос — строки 34-36, 86-102).
7. **`mysqli_report(MYSQLI_REPORT_OFF)`** в `config.php:32` — ошибки БД глушатся.
8. **Не реализовано из ТЗ:** `import.php` (импорт CSV) отсутствует, `service.php` (Услуги) отсутствует.
