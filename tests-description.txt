Тесты проекта comp
====================

Запуск
------
Все тесты (unit + integration):
  .\run_integration_tests.ps1   (PHPUnit + запуск PHP built-in сервера)

Только unit (без сервера):
  C:\xampp\php\php.exe .\phpunit.phar --testsuite=unit

Только integration (нужен сервер на порту 8899):
  C:\xampp\php\php.exe .\phpunit.phar --testsuite=integration

Фильтр по классу:
  C:\xampp\php\php.exe .\phpunit.phar --testsuite=integration --filter=TmcFullTest
  C:\xampp\php\php.exe .\phpunit.phar --testsuite=unit --filter=ControlsTest

Testdox (читаемый вывод без деталей):
  C:\xampp\php\php.exe .\phpunit.phar --testsuite=integration --filter=TmcFullTest --testdox

Всего: 107 тестов, 245 assertions (31 unit / 76 integration)
