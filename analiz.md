## Архитектура проекта «Comp» — CRM/ERP-система

---

### 🏗 Общая картина

Это **полностью кастомная CRM/ERP-система** на русском языке для управления бизнесом (клиенты, товары, накладные, продажи, склад, кассовая книга, услуги, сотрудники). Проект написан с нуля **без использования внешних фреймворков** — ни PHP, ни JavaScript.

---

### 📦 Технологический стек

| Слой | Технология |
|---|---|
| **Backend** | Чистый PHP (без фреймворка, `mysqli`) |
| **Frontend JS** | Vanilla JavaScript (ES6+, IIFE, без jQuery/React/Vue) |
| **CSS** | Кастомный, CSS custom properties |
| **БД** | MySQL, база `comp` (~38 таблиц) |
| **Сборка / CI/CD** | **Нет** — ни `package.json`, ни `composer.json`, ни Docker |

---

### 🧱 Архитектурный паттерн: **TablePage + FormModalCore**

Проект реализует собственный «фреймворк» вокруг двух ключевых концепций:

```
┌─────────────────────────────────────────────────────────────┐
│  index.php → редирект на стартовую страницу (client.php)    │
└─────────────────────────────────────────────────────────────┘
        │
        ▼
┌──────────────────────┐     ┌──────────────────────────────┐
│   TablePage (lib/)   │     │   FormModalCore (assets/)     │
│  ─ список записей    │────▶│  ─ модальная форма            │
│  ─ поиск/сортировка  │     │  ─ создание/редактирование    │
│  ─ фильтрация        │     │  ─ AJAX сохранение            │
│  ─ пагинация         │     │  ─ inline-edit               │
│  ─ mark/unmark       │     │  ─ lookup-выборки            │
└──────────────────────┘     └──────────────────────────────┘
        ▲                              │
        │                              ▼
┌───────┴──────────┐        ┌────────────────────┐
│  config/*.php     │        │  lib/controls.php   │
│  ─ столбцы        │        │  lib/template.php  │
│  ─ SQL-запросы    │        │  lib/SimplePdf.php │
│  ─ фильтры        │        │  lib/sum_propis    │
└──────────────────┘        └────────────────────┘
```

### 📋 Паттерн файла сущности

Для каждой из **29 сущностей** создаётся набор файлов:

| Файл | Назначение |
|---|---|
| `config/{entity}_columns.php` | Определения столбцов (имя, метка, сортировка, поиск) |
| `config/{entity}_page.php` | Конфиг TablePage (SQL, дефолтная сортировка, фильтры) |
| `{entity}.php` | Главная страница — таблица со списком |
| `{entity}_form.php` | Модальная форма (создание/редактирование/удаление) |
| `{entity}_field_save.php` | AJAX-сохранение инлайн-редактирования |
| `{entity}_export.php` | Экспорт в CSV/XLS |
| `{entity}_print.php` | Печатный вид (HTML) |
| `{entity}_columns_save.php` | Сохранение видимости/порядка столбцов |
| `{entity}_column_width_save.php` | Сохранение ширины столбцов |

---

### 🔄 Механизм запросов

**Нет REST API и фронт-контроллера.** Каждая страница — самостоятельный entry point. AJAX определяется по параметру `$_GET['ajax']` / заголовку `X-Requested-With`:

```
GET  {entity}.php              → полный HTML (таблица)
GET  {entity}.php?ajax=1       → JSON {ok, html, mode, ...}
POST {entity}_form.php          → JSON (сохранение формы)
POST {entity}_field_save.php    → JSON (инлайн-редактирование)
```

### 🗄 База данных

- **MySQL**, база `comp`, **38+ таблиц** (клиенты, товары, накладные, продажи, склад, платежи и т.д.)
- **Нет SQL-миграций** — схема создаётся/модифицируется автоматически в PHP-коде (`ensure_*_table()` в `config.php`)
- Перси́стентность настроек: видимость столбцов, их ширина и порядок — хранятся в таблицах `column_visibility` и `app_settings`

### 🎨 UI и UX

- **Тёмная тема**: `#2f3e4e` (основа), `#e67e22` (оранжевый акцент), плоский дизайн
- **Модальные формы** (не переход на отдельную страницу)
- **Инлайн-редактирование** прямо в ячейках таблицы
- **Lookup-выборки** для FK-связей с поиском и кнопкой «+»
- **Горячие клавиши**: Insert (новый), Delete (удалить), Enter (открыть), стрелки, PgUp/PgDn
- **Многоколоночный поиск, сортировка и фильтрация**
- **Вложенные подтаблицы** (например, позиции внутри накладной)
