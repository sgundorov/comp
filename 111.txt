Функция проверки наличия товара с учетом бронирований check_bronir():

Если voz_flag==True или docum.voz_flag==True, то ничего не делать.

Если товар "Без количества" (product.noquant_flag==True):
  Делается проверка по docum2 с заданным product_id занятости данного товара на период с времени начала данного заказа (docum.date_beg и docum.time_beg) по время возврата заказа (date_voz и time_voz), у которых typeop==90 и voz_flag != True. При этом учитывается что docum_id заказа не должен быть равен docum_id текущего заказа.

Если при этой проверке находится хотя бы один не завершенный заказ (voz_flag != True), то пользователю выводится  сообщение: product.name .'занят на это время!'. Также при этом обнуляются поля product_id, code, product_name, price, price_id, и функция check_bronir() возвращает True.

Иначе функция check_bronir() возвращает False.


Если признак товара "Без количества" не включен (product.noquant_flag==False):

Если days > 0:
  Для каждой даты заказа (с date_beg по date_voz) определяется остаток товара с учетом выданных в прокат и забронированных. При помощи функции quant_date(date, product_id, docum_id).
Находится минимальный остаток товара за все дни проката.

Если days == 0:
  Находится остаток товара на дату начала проката при помощи функции quant_date(date, product_id, docum_id, store_id).

Если docum2.quant > минимального остатка товара:
  Выводится сообщение: "'Товар '. product.name .'.  Доступно: '. min_quant".
  Присваивается: docum2.quant = минимальный остаток товара
  Также обнуляются поля product_id, code, product_name, price, price_id, и функция check_bronir() возвращает True.

Иначе функция check_bronir() возвращает False.


-----
Функция quant_date(date, product_id, docum_id):
Возвращает остаток товара на заданную дату путем суммирования количества заданного товара во всех документах движения товара (по записям таблицы docum2). При этом учитываются записи у которых docum2:product_id == product_id, docum2.docum_id != docum_id. 

Для документов типа "Приход" (typeop==20) и "Возврат от покупателя" (typeop==40) количество учитывается со знаком "плюс". Только если включен docum2.accept_flag.

Для типов "Продажа" (typeop==120), "Списание" (typeop==127) и "Возврат поставщику" (typeop==110) количество учитывается со знаком "минус". Только если включен docum2.accept_flag.

Для документов типа "Ремонт" (typeop==100) количество учитывается со знаком "минус" но только если docum2.voz_flag==False. Иначе количества "Ремонта" не учитывается. При этом docum2.accept_flag не учитывается.

Для документов "Аренда" (typeop==90) количество учитывается со знаком "минус" только если товар не возвращен (docum2.voz_flag==False). А также только если (docum2.date_beg <= date и docum2.date_voz >= date). При этом docum2.accept_flag не учитывается.

Функция получения тарифа товара get_price():

Если товар не выбран (product_id==0), то return.

Если включен параметр настройки "Тарифы вводятся вручную", то делается вызов функции calc_sum() и return.

sum_zalog = product.zalog;

  sum_zalog = 0;

Если product.period_aren=='m', то price = price_month
Если product.period_aren=='d', то price = price_day и price_we = price_day
Если product.period_aren=='h', то price = price_hour


Если включен параметр настройки	"Использовать сезоны тарифов" (g:SezonFlag), 
то в таблице prplan находится нужная запись о тарифном плане и она записывается в docum2.prplan_id.
Запись в prplan находится по условию: (docum.date_beg >= prplan.bdate и docum.date_beg <= prplan.edate)
Если в prplan нет записи, удовлетворяющей этому условию, то docum2.prplan_id не изменяется (он по умолчанию равен 1).

В таблице price описана зависимость тарифа от времени аренды (от числа часов и дней).
Записи в price ищутся для тарифного плана price.prplan_id==docum2.prplan_id и price.product_id==docum2.product_id.
Если параметр настройки g:FixedFlag==False то используются только записи таблицы price у которых price.fixed_flag==False. 
Если g:FixedFlag==True то используются только записи таблицы price у которых price.fixed_flag==True.

Для определения тарифа за час (docum2.price_hour) используются записи у которых указана price.hprice и price.etime. Выбирается тот тариф, у которого price.btime >= docum2.hours и price.etime <= docum2.hours
Для фиксированных тарифов (g:FixedFlag==True) найденный тариф записывается в docum2.price_fix.

Для определения тарифов за день (docum2.price_day и docum2.price_we) используются записи у которых указана price.price и price.edays. Выбирается тот тариф, у которого price.bdays >= docum2.days и price.edays <= docum2.days
Для фиксированных тарифов (g:FixedFlag==True) найденный тариф записывается в docum2.price_fix.

docum2.price_day - Тариф буднего дня
docum2.price_we  - Тариф выходного дня
Если тариф выходного дня равен 0, то docum2.price_we = docum2.price_day.

После выбора тарифов функция get_price() выполняет calc_sum() и return.

  if (g:FixedFlag==True)  {   // Фиксированные тарифы (не зависят от времени)

          loc:ProsrHours = clock() + g:TimeShift - time_voz;   // Время опоздания
        }
        // Если просрочка больше допустимого времени опоздания
        if (g:TimeOpozd > 0 and loc:ProsrHours >= g:TimeOpozd) {
          // Если не включен "Не изменять число дней досрочном возврате"
          if (g:VozDateFlag==False and date_beg != date_voz) {    
            loc:Days = docum2.days + 1;    // Если опоздание по часам
            loc:Hours = 0;
          }
        }
      }
    }

        loc:DaysWeekEnd = weekend_quant(docum2.date_beg, docum2.date_voz);   // Кол-во выходных дней за период
        loc:Days -=  loc:DaysWeekEnd;   // Минус количество выходных дней

        loc:Price  = docum2.price_day;
        loc:HPrice = docum2.price_hour;
        loc:WPrice = docum2.price_we;    // Тариф выходного дня
        loc:MPrice = docum2.price_month;
        if (loc:WPrice == 0) {
          loc:WPrice = loc:Price;
        }  
        if (firm.nonds_flag and client:jur_flag)  {   // Если цена без НДС (только для организаций)
          loc:Price  *= (100 + g:NDS)/100;
          loc:HPrice *= (100 + g:NDS)/100;
          loc:WPrice *= (100 + g:NDS)/100;
          loc:MPrice *= (100 + g:NDS)/100;
        } 
        docum2.sum_discount = loc:Price * loc:Days * (docum2.discount/100) + loc:HPrice * (loc:Hours/36000) * (docum2.discount/100);
        docum2.sum = loc:Price * loc:Days * (1-docum2.discount/100) + loc:Price * (loc:Hours/360000) * (1-docum2.discount/100);
        docum2.sum_discount  += loc:WPrice * loc:DaysWeekEnd * (docum2.discount/100);
        docum2.sum += loc:WPrice * loc:DaysWeekEnd * (1-docum2.discount/100);

        if (g:ShowMonthFlag and product.period_aren=='m') {
          docum2.sum_discount  = loc:MPrice * loc:Months * (docum2.discount/100);
          docum2.sum  = loc:MPrice * loc:Months * (1 - docum2.discount/100);
        }

        if (docum2.sum < 0) {
          docum2.sum = 0;
        }
  }

  if (product.noquant_flag==False and docum2:quant > 1) {   // Учитывать количество
    docum2.sum *= docum2:quant;
    docum2.sum_discount  *= docum2:quant;
    docum2.sum_zalog *= docum2:quant;
  }
